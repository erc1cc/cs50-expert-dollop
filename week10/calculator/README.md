#### Description:
This calculator features many more features than your average calculator. First, the calculator. We create an HTML file with all the buttons. Within the buttons, we add an 'onclick' attribute. This makes it so that when we click a button, a function is called to append the corresponding value of the button to the display. Certain buttons will have unique functions, such as 'C' and '='. C will just clear the display value, and the equals symbol will calculate our equation. We will calculate our equation using the built in eval() function. Then, we use CSS to style the buttons. First of all, with HTML, we assign an id to the display, so that we can save our inputted values via javascript. We also make the display readonly so you can't just type a certain equation in. Using CSS, we assign the buttons a set of style tags. This adds color to the buttons, making them gray, adding a radius so that the buttons appear circular, and we also make the operator buttons orange for aesthetic purposes. Using pseudo-classes, we can add a lighter shade of color to the buttons. This gives a signal to the user so that they know that the button is pressed and used. It is also nice for aesthetic purposes. Below the buttons are the other miscellaneous parts of the program. First, we have a history section which records the equations and the answers the user has inputted. Then, we have a list of the extra features this program includes, such as button sound effects, personalization, and easter eggs. With button sound, what I did was I downloaded a certain click sound from a website on the internet, and then I used javascript to play that sound. Then, within each javascript function for the respective buttons I added the playSound() function. First we have the calculate function. This function is meant to calculate our equation, and it also includes various easter eggs. When the answer to your equation is 69, you are alerted "bruh". If the result is 822008, which is my birthday, you get alerted that it is my birthday. You will also be alerted if the result is my current age this year and the current year it is.
I debated on adding more dates, but I thought that that would be too much to keep track of. Next, I used flask inside my program. I originally planned to just use http-server for this project, but that was scrapped when I thought I should make a separate page for history. In the beginning, I was going to create my own SQL database for history, which also had its own page, but I scrapped that too when I realized I could just incorporate history inside the main page. I also think that I don't need an actual SQL database beacuse I didn't want the list of previous equations to be too long. How I added the history function was that I first added a div tag with an id of "history," and then within my calculate function of the javascript file, I used .innerHTML to append to the div tag such that it followed a certain format. That format was the display value = the result of the equation. With personalization, I added a little trademark tag at the bottom of my HTML page. The format I used was copied off of Apple's website, and I thought that was a pretty cool little thing that I could add to my project that would really represent my work. Since I used flask in my program, I had to edit the links to my different source files into a different format so that they would actually work.
